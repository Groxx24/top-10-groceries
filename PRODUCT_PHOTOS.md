# Product photos

`GenericProduct` and `ui/deal/ProductPhotos.kt`). Each is a public-domain or CC0 photo, found
through Wikimedia Commons or Openverse, cropped square and scaled to 256 px. Neither licence
requires credit, so none is shown in the app; this list is here so each one can be traced back.
A new one must be public domain or CC0 too, unless the app gets a credits screen.
